# What's New in V3.0.14

- [](/_docs/)- Release Notes- What's New in V3.0.14# What's New in V3.0.14
Release Date: August 15, 2025

Email-Based Service Management Integration – Configure integrations with platforms like JIRA and FreshDesk to send incidents and issues. This is configured in the Admin Console.

SageMaker Discovery Enhancements – Expanded discovery of SageMaker resources with an enhanced dependency graph and issue creation.

Model Scanning Improvements – Detect vulnerabilities in discovered model artifacts saved in LFS format.

Pentest Reports – Updated penetration test reports.

MCP Server Discovery – Added support for MCP server and MCP tool discovery to govern agentic systems.

AWS StackSet Discovery – Link multiple AWS accounts or OUs for discovery using AWS Stacksets. Continuously link and perform discovery on new AWS accounts.
