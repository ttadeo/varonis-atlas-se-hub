# What's New in V3.0.12

- [](/_docs/)- Release Notes- What's New in V3.0.12# What's New in V3.0.12
Release Date: July 18, 2025

Model Scan – Expanded support for scanning model packages and artifacts.

Model Scan Reports – Updated model scan reports.

Inventory Technologies – Redesigned tab for improved navigation, usability and management of AI Inventory.

Sensitive Data Issues – Issues are now displayed in a dedicated Sensitive Data section and can be viewed on dependency graphs for AI Systems containing vulnerable dataset resources.

Gateway Policies – Added new LLM-as-a-Judge and Banned Substring guardrail rules.
