# GUI Overview

- [](/_docs/)- Overview- GUI Overview# GUI Overview
The system enables rapid AI adoption in a safe, secure, and compliant manner. The platform delivers multiple applications that support different stages of the safe AI lifecycle, offering various functions to implement controls, processes, and guardrails for reducing risk.

As AI becomes increasingly pervasive across organizations, GRC teams are now responsible for reviewing, securing, and monitoring a rapidly expanding list of AI systems. The platform is designed to streamline this process, with a GUI structured to facilitate comprehensive governance of each AI system throughout the entire AI lifecycle. It organizes the necessary steps and areas of focus into an intuitive, easy-to-navigate interface, enabling organizations to manage and safeguard their AI systems effectively.

The GUI features a main panel in the center, a left-hand-side (LHS) menu bar, a top tab bar, and an organization drop-down menu at the top left. An alternative layout omits the top bar and instead places sub-menu items in the LHS menu bar. The LHS menu bar allows you to select an application or functional domain (e.g., AI Runtime Protection or AI SPM), while each top tab provides different views within that domain (e.g., dashboards, issue lists, policies). Each selection from the LHS menu and top tabs updates the main panel based on the chosen application and activity. The organization drop-down menu displays the hierarchy of organizations and projects you belong to and can work on. This selection affects the data displayed in the main panel. For instance, selecting "AI Inventory" from the LHS and "Technologies" from the top tab lets you view the technologies in use, filtered by the organization or project selected in the organization drop-down menu.
