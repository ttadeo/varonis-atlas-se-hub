# Log Sources

- [](/_docs/)- [Admin Console](/_docs/docs/admin_console/)- Log SourcesExport PDF# Log Sources
Log Sources let you bring AI activity that happens outside the Atlas inline gateway into Atlas for offline policy evaluation, alerting, and investigation.

You still manage them from **Admin Console &gt; System Settings &gt; Log Sources**. For how they work and how to configure each source type, see the **[Log Sources](/_docs/docs/log_sources/overview)** section:
