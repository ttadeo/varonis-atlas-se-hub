# Admin Console

- [](/_docs/)- Admin ConsoleExport PDFOn this page# Admin Console
The Admin Console is the tenant administration area for tenant settings, integrations, directory management, roles, API keys, system audit logs, data plane administration, and runtime evaluator LLM settings. Use it to invite and manage users, assign role-based permissions, scope user access to projects and organizations, and configure platform-level services.

## Accessing the Admin Console[​](#accessing-the-admin-console)
Open the Admin Console by selecting it from the top-right menu (under your profile icon). You need to have either the **Admin** role or the **Security Administrator** role to access the Admin Console.

## Areas of the Admin Console[​](#areas-of-the-admin-console)
The Admin Console is organized into the following sub-areas. Each sub-area has its own page with full configuration details.

- **[General](/_docs/docs/admin_console/general)** — Company profile, organizations, projects, users, roles, API keys, and system audit logs.
- **[Notifications](/_docs/docs/admin_console/notifications)** — Tenant defaults and per-user preferences for email notifications about system events.
- **[SIEM](/_docs/docs/admin_console/siem)** — Configure SIEM integration endpoints for Splunk HEC, Datadog, Panther, and Microsoft Sentinel.
- **[Service Management](/_docs/docs/admin_console/service_management)** — Send AI incidents to a ServiceNow instance or to an Email destination.
- **[Integrations](/_docs/docs/admin_console/integrations)** — Connect to additional third-party services beyond SIEM and Service Management.
- **[Runtime Logging](/_docs/docs/admin_console/runtime_logging)** — Control verbosity and destinations of runtime logs.
- **[Log Sources](/_docs/docs/admin_console/log_sources)** — Manage the log sources that feed the system.
- **[Data Plane](/_docs/docs/admin_console/data_plane)** — Administer the data plane components that process traffic for your tenant.
- **[Runtime Evaluator LLM](/_docs/docs/admin_console/runtime_evaluator_llm)** — Set the LLM the system uses for report generation, pentest evaluations, and guardrails, and configure its budget.
