# What's New in V3.0.7

- [](/_docs/)- Release Notes- What's New in V3.0.7Export PDFOn this page# What's New in V3.0.7
Release Date: April 12, 2025

## Admin console invitations[​](#admin-console-invitations)

- No longer require passwords
- Invitation is similar to Auth0 invitations
- Support google-oauth2 invitations

## Inventory[​](#inventory)

- Enhanced support for Azure OpenAI and Azure ML
- Easier configuration for Azure connections

## New TPRM module[​](#new-tprm-module)
TPRM now supports full process flows and questionnaires for managing the AI verification and inventory validation for AI usage by vendors using AI-BOMs.

## Documentation[​](#documentation)

- Added Kong integration documentation.
- Enhancements to AI 360 documentation.
- GraphQL API documentation.

## Admin Console[​](#admin-console)
Invite User replaces user creation as a more secure method to add users who set their own passwords.
