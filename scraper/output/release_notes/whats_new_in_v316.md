# What's New in V3.1.6

- [](/_docs/)- Release Notes- What's New in V3.1.6Export PDFOn this page# What's New in V3.1.6
**Release Date: April 10, 2026**

### Azure Data Plane Support[​](#azure-data-plane-support)
Adds support for deploying the data plane in Microsoft Azure, in addition to AWS. The Azure data plane provides the same AI Runtime functionality as the AWS deployment model, allowing customers to keep rule evaluation and runtime traffic processing within their own Azure environment while continuing to use the SaaS control plane for centralized management.

### AI Observability Removed[​](#ai-observability-removed)
Removes the legacy AI Observability experience and completes the deprecation of OpenSearch from the platform. Logging, alerting, and investigation workflows are now handled natively in AI Investigation, which provides the same core observability capabilities along with deeper investigation workflows and a more integrated product experience.

### SIEM Configuration Moved to Admin Console[​](#siem-configuration-moved-to-admin-console)
Relocates SIEM event configuration from the legacy Observability area to the SIEM tab in Admin Console. This centralizes external event forwarding setup in a more consistent administrative experience.

### AI Evaluations and Datasets Moved to AI Red Team[​](#ai-evaluations-and-datasets-moved-to-ai-red-team)
Moves AI Evaluations and Datasets into the AI Red Team feature. This aligns these workflows more closely with testing and validation activities and simplifies navigation by grouping related offensive security and evaluation capabilities together.

### Expanded Performance Metrics and Alerting in AI Investigation[​](#expanded-performance-metrics-and-alerting-in-ai-investigation)
Enhances performance metrics in AI Investigation with new hourly, daily, and weekly interval views in addition to the existing 5-minute view. This release also adds 5-minute and hourly alerting for performance metrics, helping teams detect and respond to unusual changes in system performance more effectively.

### Resource Tagging in Inventory[​](#resource-tagging-in-inventory)
Adds support for structured resource tagging across inventory. Tags can now be configured from both the inventory list view and individual resource detail pages, making it easier to organize resources, improve filtering, and support governance workflows across projects.
