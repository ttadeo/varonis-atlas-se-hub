# What's New in V3.0.13

- [](/_docs/)- Release Notes- What's New in V3.0.13# What's New in V3.0.13
Release Date: August 1, 2025

Agentic Discovery – Added a new code scanning tool for Agentic Discovery. Discover agents, sub-agents, and tools from code repositories.

Admin Console – Added ability to delete organizations and projects.

Dataset Sensitive Data Scanning – Sensitive data detection now available for Azure ML and Azure OpenAI datasets.

Inventory Issues – Introduced bulk actions on the Shadow AI issues page along with a new review side panel to facilitate addressing Shadow AI issues.

Compliance – Launched the new AI TRISM Assessment framework.

TPRM Vendor Inventory – AI-BOM integration with vendor assessments, generating vendor inventory and CVE issues.
