# What's New in V3.0.11

- [](/_docs/)- Release Notes- What's New in V3.0.11Export PDF# What's New in V3.0.11
Release Date: June 27, 2025

Reporting – New Generate Report functionality for all modules to export events from the Varonis platform. This feature can be accessed via the Report tab.

Sensitive Data Scanning – Scan datasets used to train and test AI Systems for sensitive data. Review findings in the SPM module.

Compliance Risk Assessments – Upgraded Compliance Risk Assessment flow. Risk Assessments now support a new dynamic UX performed entirely in the platform.
