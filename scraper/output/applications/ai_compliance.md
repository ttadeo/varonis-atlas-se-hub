# AI Compliance

- [](/_docs/)- Applications- AI ComplianceOn this page# AI Compliance
The AI compliance applications allows you to ensure compliance with AI regulations, frameworks and best practices. Using the system you can initiate audits for your projects and generate compliance reports.

In the Dashboard tab you can view all your active, completed and suggested compliance workflows. For completed audits you can download the audit report and deliver it to your auditors. The compliance application maps your AI systems / projects to the compliance mandates and/or framework and for each shows your compliance posture.

Initiate a compliance workflow either from the Audit tab or the Compass tab. From the Audit tab, select the framework you wish to initiate and click the Initiate Audit button. Then select the project to audit, the project manager email and the due date and click Start Audit Project. This creates a project for the audit that you can access in the Dashboard tab under Active Audit Projects. An email will be sent to the project manager email you selected and the project manager can add additional members to the project.

Audits are managed as an Asana project and you can access the project using the Compliance Workflow button on the Dashboard tab which opens the project in a new tab. Note that you will have to sign in to Asana using your email.

When the compliance workflow completes your project moves to the Completed tab in the Dashboard page and you can download the audit report.

Any issue discovered during the audit appears in the Issues page and should be resolved.

## Dashboard[​](#dashboard)
When an audit is initiated from the Audit or the Compass tab, the audit appears in the Active Audit Projects list along with the completion process and audit health. Click on Compliance Workflow to open the full project plan in a separate tab. The project plan is managed within the embedded Asana instance. Note that you will have to login to Asana as a guest member if you have not already done so and that the owner of the project needs to invite you as a guest to view the process. If you get a Request access button, the owner will get a notification when you request the access and after adding you to the project you will be able to access and work to satisfy the audit and view the work.

Note: when you initiate a new audit it may take a few minutes for all the project steps to be populated so if you immediately access the workflow it may seem incomplete.

Clicking on the Completed tab allows you to download compliance reports for all completed audits.

Gaps show you which audits you should be performing given your current set of projects and that you have not initiated yet.

The compliance heatmap maps all your projects and all compliance processes and notes the completion progress for each.

## Audit[​](#audit)
You initiate audits by navigating to the Audit tab. You then pick the regulation or framework you want to use as a template and click Initiate Audit. You then select the project that is to be audited. Set the owner's email and the due date for the audit to be completed and click Start Audit Project.

## Compass[​](#compass)
Use the Compass application to have the system suggest what you should comply with. Select the project you wish to analyze from the top-left organization/project pull down. If you have never used the Compass for this project before click on the Start Compliance Mapping Questionnaire button and answer all the questions presented. Then click on Submit Responses. The system will then recommend what compliance frameworks you should activate along with justifications that you can edit.

If you have already used the Compass to perform this analysis you can edit your questions and re-assess.

## Issues[​](#issues)
The issues tab lists all issues - both operational issues pertaining to the audit itself as well as issues that need to be remediated within your AI systems that were uncovered during the audit.

## Report[​](#report)
Use the AI Compliance report to search through all AI compliance issues, present or past.
