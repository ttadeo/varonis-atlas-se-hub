# AI Compliance

- [](/_docs/)- Applications- AI ComplianceOn this page# AI Compliance
The AI Compliance application allows you to ensure compliance with AI regulations, frameworks, and best practices. Using the system, you can initiate audits for your projects and generate compliance reports.

In the Dashboard tab, you can view all your active, completed, and suggested compliance workflows. For completed audits, you can download the audit report and deliver it to your auditors. The compliance application maps your AI systems and projects to the applicable compliance mandates and frameworks, showing your compliance posture for each.

Initiate a compliance workflow from either the Audit tab or the Compass tab. From the Audit tab, select the framework you wish to initiate and click **Initiate Audit**. Then select the project to audit, the project manager email, and the due date, and click **Start Audit Project**. This creates a project for the audit that you can access in the Dashboard tab under Active Audit Projects. An email is sent to the project manager you selected, and the project manager can add additional members to the project.

Audits are managed as an Asana project. You can access the project using the **Compliance Workflow** button on the Dashboard tab, which opens the project in a new tab. Note that you will need to sign in to Asana using your email.

When the compliance workflow completes, your project moves to the Completed tab on the Dashboard page, where you can download the audit report.

Any issue discovered during the audit appears in the Issues page and should be resolved.

## Dashboard[​](#dashboard)
When an audit is initiated from the Audit or the Compass tab, it appears in the Active Audit Projects list along with completion progress and audit health. Click **Compliance Workflow** to open the full project plan in a separate tab. The project plan is managed within the embedded Asana instance. Note that you will need to log in to Asana as a guest member if you have not already done so, and the project owner must invite you as a guest to view the process. If you see a **Request access** button, the owner receives a notification when you request access. After the owner adds you to the project, you can access the workflow and work to satisfy the audit requirements.

Note: when you initiate a new audit, it may take a few minutes for all the project steps to be populated. If you access the workflow immediately, it may appear incomplete.

Clicking on the Completed tab allows you to download compliance reports for all completed audits.

Gaps show you which audits you should be performing given your current set of projects but have not yet initiated.

The compliance heatmap maps all your projects against all compliance processes and shows the completion progress for each.

## Audit[​](#audit)
Initiate audits by navigating to the Audit tab. Pick the regulation or framework you want to use as a template and click **Initiate Audit**. Then select the project to be audited, set the owner's email and the due date, and click **Start Audit Project**.

## Compass[​](#compass)
Use the Compass application to have the system suggest which frameworks you should comply with. Select the project you wish to analyze from the top-left organization/project dropdown. If you have never used the Compass for this project before, click **Start Compliance Mapping Questionnaire** and answer all the questions presented. Then click **Submit Responses**. The system recommends which compliance frameworks you should activate, along with justifications that you can edit.

If you have already used the Compass to perform this analysis, you can edit your questions and re-assess.

## Issues[​](#issues)
The Issues tab lists all issues, including both operational issues pertaining to the audit itself and issues that need to be remediated within your AI systems that were uncovered during the audit.

## Report[​](#report)
Use the AI Compliance report to search through all AI compliance issues, present or past.
