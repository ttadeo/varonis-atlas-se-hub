# AI Monitor

- [](/_docs/)- Applications- AI MonitorOn this page# AI Monitor
The AI Monitor application augments AI Observability with useful tools in order to implement AI Activity Monitoring (AiAM).

## Dashboard[​](#dashboard)
View issues generated by the AI Gateway for certain time ranges and categorized by guardrail.

For each guardrail click on Alert Setting to set absolute or relative thresholds and alerts will be generated when event occurrence of that category exceeds the threshold.

## Issues[​](#issues)
View all open and closed alerts based on the alert configuration.

## Report[​](#report)
Use the AI Monitor report to produce reports on alerts.
